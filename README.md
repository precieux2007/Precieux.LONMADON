> *Relancé en septembre 2026*

Une plateforme pour les étudiants de l'**Université d'Abomey-Calavi (UAC)** et d'autres universités du Bénin.

- 📚 **Étudiants** : accès digital aux cours et aux résultats d'examens
- 👨‍🏫 **Professeurs** : fini les tracas pour modifier les horaires, changer les salles de cours ou gérer les photocopies
- 🎯 **Objectif** : simplifier la vie académique et la rendre 100 % digitale

- 🚀 Un projet d'ingénierie, d'innovation et de fierté continentale

🔗 **[Voir le projet →](https://github.com/precieux2007/PLAYSTATION)**
